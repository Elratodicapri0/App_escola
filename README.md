##App Escola

Este é um sistema para gerenciamento escolar, permitindo o cadastro e acompanhamento de alunos, professores, turmas e disciplinas.

##Funcionalidades

Cadastro de alunos e professores

Gerenciamento de turmas e disciplinas

Relatórios e acompanhamento de desempenho

##O que foi feito

O código consiste em um projeto de sistema para a secretaria, com diversas funcionalidades, como adicionar alunos, selecionar suas turmas e vinculá-los a um responsável, além de alterar seu número de faltas.
Para iniciar os testes no sistema, é necessário primeiro cadastrar um aluno, um professor e um responsável, pois somente assim todas as funcionalidades do código estarão disponíveis.
Na seção de atividades pendentes, é possível definir quais alunos estão devendo atividades, anexar uma descrição sobre a pendência e adicionar a matéria/bimestre correspondente (o bimestre deve ser iniciado por um administrador na área de bimestres, apenas informando o número correspondente).
Também é possível adicionar eventos extracurriculares caso o aluno tenha se inscrito. Para isso, é necessário informar o ID do professor responsável pelo evento, a data, o título e uma descrição sobre ele.
Na parte de notas, deve-se selecionar o aluno e adicionar o bimestre e a matéria à qual a nota pertence.
Em "pagamentos pendentes", o funcionamento é semelhante ao de adicionar eventos. No entanto, basta selecionar o aluno, informar o valor atualizado da pendência, a data de vencimento e adicionar uma descrição sobre o que se refere aquele pagamento.
